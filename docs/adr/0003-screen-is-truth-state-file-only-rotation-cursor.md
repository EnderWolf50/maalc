# 中途接續以畫面為準，狀態檔只存輪替游標

使用者可能在兩次啟動 bot 之間自己玩，例如手動跑完一局、換隊、用掉每週獎勵。這些都會讓存檔的狀態過時。所以中途接續完全靠畫面判斷，不讀存檔；Agent 的狀態檔只記一件事：下一局輪到哪一隊（輪替游標）。

除了游標，其餘狀態每次都從畫面重新讀取（2026-10-13 在 Limbus 1.116.2 實機確認）：

- 鏡牢入口頁：有沒有暫停中的局、它在第幾層和難度，例如 `Exploring: … - F1` 與 `Automated Factory [NORMAL]`；Weekly Bonuses 剩幾次。
- 設定面板、Resume 對話框：每一層的難度和進度，例如 `Floor 1 [NORMAL] 0/6`。
- 主題包頁：本層難度，可以切換；遊戲會記住上一次選的難度。
- 地圖頁：`Exploring Floor N`、主題包名稱、身上的飾品。
- 選隊頁與戰前編隊頁：用的是哪一隊，例如 `TEAMS #N`。

## Considered Options

- **用完整的帳本記錄每一步（MaaLimbus）**：不採用。帳本會和實際畫面對不上；MaaLimbus 就遇過帳本記第 2 隊、遊戲實際跑第 1 隊。
- **送出關鍵操作前，先記下正要做什麼**：先不做。重開後畫面本身會反映操作有沒有完成，跟著畫面走就不會重複執行。之後如果出現既不能重複、又無法從畫面判斷做過沒有的操作，再加。

## Consequences

- 輪替游標只在 bot 親眼看到「某隊完成一局並領到獎」才前進。手動跑的局不影響輪替；編隊頁顯示的隊伍和游標不同時，以畫面為準。
- 「跑幾輪」只算 bot 這次啟動後完成的局數，不存檔。另有選項「每週獎勵用完就停」，剩餘次數直接從畫面讀。
- 困難或普通、每週獎勵怎麼用這類策略，屬於 GUI 選項，不寫進狀態檔。

## 修訂（#436，2026-11-08）

- 戰前編隊頁不顯示隊伍（`tests/screens/Formation.png`），上面「選隊頁與戰前編隊頁」那一項只對選隊頁成立。選隊之後，地圖、進度面板、Resume 對話框、入口頁與結算頁也都沒有 `TEAMS #N`（`tests/screens/` 的這些畫面），所以 Consequences 第一項「編隊頁顯示的隊伍和游標不同時，以畫面為準」做不到。
- 接續的局（Agent 中途重啟、Resume 暫停中的局）改從輪替游標推回隊伍：游標只在領獎時前進，bot 開的局用的就是開局時從游標選出的隊伍。設定的難度是 `hard` 或 `normal`、是 `auto` 而目標層數大於 5（這時一定開在困難，[spec 04](../spec/04-settings.md#5-執行選項run) 第 5 節，#385），或兩種難度從游標選到同一支隊伍時，就是那一支，結算後游標照常前進；推不回就不推進。狀態檔仍然只存輪替游標。
- 這改了「手動跑的局不影響輪替」的一部分：使用者手動開、暫停後交給 bot 接續的局，畫面分辨不出來，也算游標那支隊伍的局，領獎後游標前進。bot 沒接手的手動局照舊不影響。
