## Mechanics learned
- Entry chain: Enter dialog -> team picker (Confirm) -> level warning (avg 40 < recommended 60) -> Starlight/Grace page (Enter, select nothing, confirm; unused Starlight goes to clear rewards) -> starting gift (keyword cabinet -> gift -> Select -> GET popup) -> E.G.O Gift Search (Refuse + Confirm) -> theme pack page.
- Difficulty toggle sits on the floor 1 theme pack page only (arrows at 850/897,46 when HARD; 918/965 when NORMAL). From floor 2 on the arrows are greyed out.
- Theme pack Refresh is free once per floor, then greys out. Packs can carry EFFECTIVE stamps (match team affinities) or a hazard badge. You pick a pack by swiping its card downward.
- Map: the bus sits in one column; you can only enter nodes linked to the bus by a lit line in the next column. Tapping any other node does nothing (no feedback). About 2 columns ahead are visible and the map pans freely. Nodes: battle (crossed swords + Cost 85 + affinity icons), focused (orange WARNING ring, gift + Cost 150-180), abnormality (creature icon, gift + Cost 120), event (?), shop (counter icon, panel shows the next boss), boss (red hazard, gift + Cost 250/300). Selecting a node zooms in and opens a right panel (name, Clear Rewards) with Enter (1133,543). The bottom bar then dims sinners 7-12 (deploy preview).
- Formation: up to 7 SELECTED plus up to 5 BACKUP (Entry SP +15/+20/+30), "Total Participants n/12". The selection persists between battles. To Battle at (1145,587).
- Battle by touch: Win Rate button sits on the right gear (x moves +38 px per extra skill slot each turn: 1004/1015/1042/1053/1080...; y=545). Tapping it auto-assigns skills and turns the gear disc bright orange with a START label. Then tap the disc at (winrate_x-95, y+12). Tapping Win Rate again toggles the assignment OFF. There is no separate result screen: VICTORY banner -> loading "Combat Tips" -> map, or gift/reward-card pages.
- Rewards order after a focused/boss fight: Acquire E.G.O Gift page -> E.G.O Gift GET popup(s) -> Select Encounter Reward Card (Selectable 0/1). Cancel without a card asks "Continue without choosing a reward?". Special Catalogue gift = +1 card choice.
- Hard post-boss: 4 columns, each pairing a gift with a Mounting Trial (Enemy Level Up +1/+2). Select 0/2 takes both halves of each column. It goes straight to the next floor's pack page (no floor-transition screen).
- HP/SP carry over between nodes and floors (the bottom bar shows HP number + SP badge; damaged values drop, e.g. 248 -> 98). The Shop heal: single (50% HP + 45 SP), all (20% HP + 15 SP), revive (greyed when nobody is dead), each 100 Cost.
- Shop: Refresh 15 -> 30 (price rises per use), Keyword Refresh 90 -> 105. Spending Cost raises "Super Shop On Next Floor?" (3% -> 24%). The Super Shop had 10 offers, including "ID Skill Search" priced in STARLIGHT (avoid) and Replace-skill items. Enhance: + costs 60, ++ costs 120. Fuse: 2-5 ingredients, keyword chance 60/90/99%; fusion itself is free, while Wishmaking costs 5 Starlight (avoid). Sell shows a price per gift. Team (100) swaps identities.
- Events: SKIP/Proceed/Continue/Commence all sit on one red button (1130,645) that greys out when inactive. Choice rows sit at (925,230/360/...) and show hints like "X & Y Advantage check. Pass to gain a <kw> E.G.O Gift". The check page shows odds captions above each portrait (Very High/High/Normal/Low/Very Low, colour-coded). Picking a sinner shows Predicted range + odds, then Commence -> coin result "Check Passed". Tap the text box to advance narration.
